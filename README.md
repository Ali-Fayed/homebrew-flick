# Homebrew tap for Flick

[Flick](https://github.com/Ali-Fayed/flick) is free, open-source file conversion at your cursor for macOS.

```bash
brew install --cask ali-fayed/flick/flick
```

Update with `brew upgrade --cask flick`. Requires macOS 14+ on Apple silicon.

The cask is generated by [`scripts/release.sh`](https://github.com/Ali-Fayed/flick/blob/main/scripts/release.sh) for each release.
