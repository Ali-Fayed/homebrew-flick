# Homebrew tap for Transflo

[Transflo](https://github.com/Ali-Fayed/transflo) is free, open-source file conversion at your cursor for macOS.

```bash
brew install --cask ali-fayed/transflo/transflo
```

Update with `brew upgrade --cask transflo`. Requires macOS 14+ on Apple silicon.

The cask is generated by [`scripts/release.sh`](https://github.com/Ali-Fayed/transflo/blob/main/scripts/release.sh) for each release.
